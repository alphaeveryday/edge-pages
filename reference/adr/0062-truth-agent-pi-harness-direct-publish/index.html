    ADR-0062: 기만 검증 에이전트는 pi 하네스로 돌리고, 검사를 통과한 결과를 사이트에 바로 게시한다¶

    • 상태: 제안됨
    • 날짜: 2026-10-20

    맥락¶

    투자정보 기만 검증(etforca.com/truth/)은 사건 JSON을 매시 갱신한다. 새 뉴스가 사건의 절차 단계(기소·판결·제재·공시)를 바꿨는지 읽고, 근거를 붙이고, 판정을 고치는 일은 모델 판단이 필요하다. 반대로 어떤 사건에 모델을 부를지, 근거가 공식 출처인지, 화면이 깨지는지는 코드가 답할 수 있다(AGENTS Rule 5).

    정해야 할 것은 세 가지다. 1. 모델이 사건 파일을 고치는 실행 틀 2. 모델이 쓸 수 있는 도구의 범위 3. 갱신 결과가 공개되는 경로

    결정¶

    • 실행 틀은 pi 하네스(@earendil-works/pi-coding-agent 1.0.4 고정)다. 기본 도구(bash·read·edit·write)와 확장·스킬·MCP·컨텍스트 파일은 모두 끄고(--no-*), 우리 확장 하나(pi/extension.ts)만 싣는다. 확장은 도구 목록을 Python(toolspec.py)에서 받아 등록하고, 호출을 python -m edge_truth_agent tool <이름>에 넘긴다. 도구 규칙의 정본은 Python 한 곳이다.
    • 도구는 코드 편집 에이전트의 검증된 패턴을 따른다. 보기 → 정확히 한 곳 바꾸기(str_replace) → 검사(check) → 끝내기(finish) 순서다. 다음 규칙은 도구가 강제한다.
    • 판정·출처·날짜 칸은 직접 고칠 수 없다.
    • 판정은 propose_verdict로만 바꾸고, 공식·공시 주소의 출처만 근거가 된다.
    • 세션에서 읽은 기사만 출처로 단다.
    • 본 뒤 바뀐 사건은 다시 보게 한다.
    • 모델은 일부 사건에만 부른다. 코드가 레이크의 1분 뉴스를 모아 사건별 이름·별칭으로 배정하고, 관련 보도 목록은 코드가 직접 붙인다. 기사에 절차 단서(기소·판결·제재·공시 등)가 있는 사건만 모델 세션을 연다.
    • 게시는 PR을 거치지 않는다. 세션 결과는 다음 순서로 공개된다.
    • 세션 결과를 계약 검사(cases.problems)한다.
    • 실제 화면 코드(truth-web)로 Chromium 렌더 검사를 한다.
    • 둘 다 통과한 사건만 비공개 버킷에 조건부 쓰기(If-Match)로 저장한다.
    • 바뀐 공개 파일만 landing 버킷 truth/data/에 올린다.

    깨진 사건은 이전 버전으로 되돌리고, 목록 화면이 깨지면 게시 전체를 멈춘다. - 사람의 정정이 우선한다. seed에 locked: true로 넣은 사건은 저장본을 덮어쓰고, 에이전트는 그 사건에 배정되지 않는다. - 키는 이 서비스 전용이다. DEEPSEEK_RESIST_NEWS_API_KEY는 pi 자식 프로세스에만 DEEPSEEK_API_KEY로 넘긴다. 다른 용도의 DeepSeek 키로 대체하지 않는다(0060과 같은 이유: 사용량·차단이 섞인다).

    대안¶

    • 사건 갱신을 PR로 올리고 사람이 머지한다: 매시 갱신이 리뷰 대기에 묶인다. 판정 규칙은 사람의 눈보다 코드 검사가 일관되게 지킨다. 사람의 개입은 seed locked 정정 경로로 둔다.
    • 모델에게 사건 JSON 전체를 다시 쓰게 한다: 바꾸지 않은 칸까지 흔들리고, 출처·판정 규칙을 사후 검사로만 지키게 된다. 한 곳 바꾸기와 읽기 전용 칸이 실패 패턴을 줄인다.
    • 자체 에이전트 루프를 직접 짠다: 대화·도구 호출·중단 처리를 다시 만드는 비용이 크다. pi는 도구를 모두 끌 수 있어 범용 하네스의 위험(셸·파일 쓰기)이 남지 않는다.
    • 모든 사건에 매시 모델을 부른다: 바뀐 것이 없는 사건에도 비용이 든다. 배정과 절차 단서 판정은 코드로 충분하다.

    결과¶

    • 좋은 점
    • 모델은 판단(읽기·요약·판정 제안)만 하고, 배정·검사·게시는 코드가 맡아 실행이 결정적이다.
    • 실패는 사건 단위로 격리된다.
    • 트레이드오프
    • 한 이미지에 Python·Node·Chromium이 함께 들어 이미지가 크다.
    • pi 버전은 형제 패키지까지 overrides로 고정해야 한다. 범위 지정으로 1.3.x가 섞이면 기동하지 않는다.
    • 의무
    • 판정·출처 규칙을 바꿀 때는 cases.py(계약)와 tools.py(세션 규칙)를 함께 바꾼다.
    • 방법론 문서(docs/design/truth-investigation-methodology.md)와 프롬프트(prompts/)의 정합을 유지한다.
